# Spellbound

A 1v1 wizard duel for the browser, played with a DualSense (PS5) controller. Built with three.js `WebGPURenderer` and TSL.

## Play locally

Requires [Bun](https://bun.sh), Chrome or Edge with WebGPU, and a DualSense (USB or Bluetooth).

```bash
bun install
bun run dev
```

Open the printed URL, connect the controller and press a button. A first click on the page turns on sound and the DualSense effects (lightbar, player LEDs and rumble over WebHID).
